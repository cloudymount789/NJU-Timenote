# NJU Timenote 功能范围与实现状态

本文档记录当前仓库已经完成什么、MCP 阶段要实现什么、哪些能力明确放到未来。后续 AI Agent 开始新任务前，应先阅读本文档，避免把未来功能误做进当前阶段。

## 1. 状态标记

- `done`：已经在仓库中完成。
- `mcp`：当前 MCP 阶段需要实现。
- `future`：未来要做，当前阶段不做。
- `blocked`：需要产品经理或后端进一步确认后才能实现。

## 5. 契约优先规则

这些点已经明确以 `docs/frontend-backend-contract.md` 为准。前端 Agent 不要再把它们当作冲突处理。

| 事项 | 当前结论 | 实现要求 |
|---|---|---|
| 周次范围 | 初始支持 1-25 周 | Course 的 `startWeek` / `endWeek` 按契约约束处理。 |
| 课程颜色 | 按课程名稳定生成 | 课程名第一次出现时可从合规色板随机分配 `colorKey`，之后同名课程复用该映射。 |
| 硬编码示例数据 | 真实应用初始状态不应有示例数据 | UI 中不得散落硬编码业务数据；如需演示数据，应集中在 mock/fake 数据源。 |
