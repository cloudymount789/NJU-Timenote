# 手动测试清单

用这份清单验证当前 Flutter 前端的首页、课表、待办、搜索、推荐、大目标拆分和本地持久化闭环。当前 App 通过 repository 访问本地 source，并使用 `shared_preferences` JSON 快照保存课程、待办、标签和设置数据；测试中仍保留纯内存 fake source。

## 启动

- [ ] App 可以安装并在 Android 模拟器或真机启动。
- [x] 首屏进入首页。
- [x] 看不到 Flutter 默认计数器或 demo 内容。
- [ ] 手机竖屏下没有明显溢出、遮挡或文字重叠。

## 首页

- [x] 顶部背景只有屏幕上方约四分之一是柔和蓝紫粉渐变。
- [x] 页面下方约四分之三保持纯白或接近纯白。
- [x] Header、三张白色卡片、卡片阴影、圆角和底部输入栏整体接近 Pencil 首页原型。
- [ ] “下一节课”和“下一件事”之间没有异常横线、背景断层、裁剪线或阴影硬边。
- [ ] 首页整体布局较紧凑，常见 Android 竖屏高度下主要内容和底部输入栏能在一屏内完整展示，页面本身不能上下滑动。
- [ ] 底部“智能一句话添加待办”栏固定在屏幕下方上层，不随首页内容移动；键盘或底部安全区域变化时不遮挡主要操作。
- [ ] 底部“智能一句话添加待办”栏和三张首页卡片阴影自然完整，没有被父容器、Stack、SafeArea 或屏幕边缘硬切。
- [ ] 首页标题显示“今天也要加油啊 ♥”，三张白色卡片横向更接近参考图宽度，整体更紧凑。
- [x] 没有课程、待办或 DDL 时展示空态，不展示伪造业务数据。
- [ ] 创建真实课程后，首页“下一节课”自动刷新并显示按当前时间计算的即将开始课程，而不是静态空态或创建顺序第一条。
- [ ] 创建真实待办后，首页“下一件事”自动刷新并显示 repository 推荐/最近待办。
- [ ] 创建 DDL 待办后，首页“DDL 提醒”自动刷新并按截止时间显示最近 1-2 条未完成 DDL。
- [ ] 首页支持下拉刷新，返回首页或重新进入时能重新读取 repository 数据。
- [x] 点击右上角设置图标进入设置页，返回后回到首页。
- [ ] 点击“下一节课”卡片进入课表页，返回后回到首页。
- [ ] 点击“下一件事”卡片进入待办页，返回后回到首页。
- [ ] 点击左下角快速挑选图标进入下一件事页，返回后回到首页。
- [ ] 点击“DDL 提醒”卡片进入默认待办页，返回后回到首页。
- [ ] 点击右下角搜索图标进入待办搜索页，返回后回到首页。
- [ ] 点击底部输入栏文字后弹出创建待办底部浮层。
- [ ] 创建待办浮层在未输入时展示一句话提示、手动创建入口、大目标拆分入口，发送按钮为禁用态。
- [ ] 在创建待办浮层输入文字后，发送按钮变为可点击状态。

## 设置页

- [ ] 设置页可从首页进入。
- [ ] 页面展示“课表与作息”和“数据与分享”两个分区。
- [ ] “课表与作息”中展示“管理学期课表”，默认至少有一个 `我的2025-2026学年第二学期课表`、`2026.3.2` 开学、持续 `16 周` 的学期课表。
- [ ] 点击“管理学期课表”进入学期课表管理页。
- [ ] 学期课表管理页可查看已有学期，点击右上角加号进入学期详情页添加新学期。
- [ ] 点击已有学期进入详情页，可编辑课表归属、学年范围、春/秋学期类型、开学日期和持续周数，保存后返回管理页并刷新。
- [ ] 学期详情页不提供“学期名称”手动输入；课表名称由课表归属、学年范围和学期类型自动生成，并作为白色详情卡片左上角标题展示，例如 `我的2026-2027学年第二学期课表`。
- [ ] 学期详情页清楚显示课表名称标题、课表归属、学年范围、学期类型、开学日期和持续周数。
- [ ] 学期详情页中学年范围可通过弹窗选择，如 `2025-2026`、`2026-2027`、`2027-2028`；学期类型可选择春季/秋季。
- [ ] 新增或编辑学期时，允许日期周范围与其它学期重叠；保存后不同课表仍按各自学期归属筛选课程。
- [ ] 长按学期条目弹出删除确认；取消后仍保留，确认后列表刷新且重启后仍已删除。
- [ ] 尚未实现的设置项清楚显示为待后续实现或禁用状态，不伪装成已完成能力。

## 主路由

- [ ] 课表页可以进入添加课表页。
- [ ] 待办页可以打开创建待办浮层。
- [ ] 所有主页面都可以返回上一页或首页。

## 课表

- [ ] 首页点击“下一节课”进入课表页。
- [ ] 无课程时，课表页展示空态，不展示伪造课程。
- [ ] 点击课表右上角加号进入添加课表页。
- [ ] 添加课表页包含“手动添加课程”和“截图添加课程”两个入口。
- [ ] 手动添加课程页可以填写课程名称、任课教师、地点和备注。
- [ ] 手动添加课程页展示“添加至”学期；默认选择上一次创建课程时选择的学期，没有上一次时选择最新创建的学期。
- [ ] 若没有任何学期课表，手动添加课程页应提示先去设置添加学期课表，不应保存到内存假数据。
- [ ] 未填写课程名称或地点时，点击“添加课程”会提示错误并保留表单内容。
- [ ] 点击“持续周次”可选择全部/单周/双周、起始周和结束周。
- [ ] “持续周次”的起始/结束周下拉范围跟随“添加至”的学期持续周数；例如 16 周学期只能选择 1-16 周，不出现 17-25 周。
- [ ] 点击“上课时间”可选择周几、起始节和结束节。
- [ ] 结束周早于起始周、结束周超过当前学期持续周数、结束节早于起始节时会提示错误，不会保存。
- [ ] 添加成功后返回课表页，并立即看到新课程。
- [ ] 添加单节、跨多节、跨上午/下午的课程后，课表中能正确显示；跨上午/下午课程应被切成两个连续块。
- [ ] 添加跨越第 8 节和第 9 节之间休息段的课程后，课表中会在晚间边界切成两个连续块。
- [ ] 在同一天同一节添加两门冲突课程后，课程块在同一格内左右排列。
- [ ] 长按课程块先弹出删除范围选择：`仅删除这一次课` / `删除所有课程`。
- [ ] 选择 `仅删除这一次课` 后再弹确认；确认后当前查看周不再显示该课程，切到其它有效周仍正常显示，重启后仍生效。
- [ ] 选择 `删除所有课程` 后再弹确认；确认后该课程所有周都不再显示，重启后仍生效。
- [ ] 删除范围选择或确认弹窗取消后课程仍保留。
- [ ] 课表页可通过第几周左右箭头切换 `1..当前学期持续周数`，课程按周次规则刷新，不出现第 0 周或越界周。
- [ ] 课表页可切换学期；切换后周数按所选学期开学日期重新计算，课程列表只展示该学期课程。
- [ ] 课表页支持下拉刷新；刷新后重新读取当前学期和当前查看周的课程。
- [ ] 课表页进入时默认显示按当前日期和学期开学日期计算出的当前教学周，而不是固定第 1 周。
- [ ] 学期开学日所在周显示为第 1 周；每过 7 天当前教学周递增 1。
- [ ] 当前日期早于开学日时，课表页默认显示第 1 周；当前日期晚于学期结束后，默认显示最后一周。
- [ ] 课表周数切换按钮在第 1 周和最后一周正确禁用，不能切到 `1..学期持续周数` 之外。
- [ ] 课表页标题、返回、加号、学期选择和周数切换位置紧凑；课表主体尽量上移且仍可读可切换。
- [ ] 课表大卡片整体更紧凑，表格宽度、高度、圆角、阴影接近参考图；无课程时仍可看到表格布局和空态提示。
- [ ] 课表切换到非当前周时，今天所在周几的蓝色高亮框不继续显示。
- [ ] 课表顶部周几下方显示具体日期，如 `06/12`。
- [ ] 点击课程块进入编辑课程页，修改课程名称/地点/周次/节次后保存，返回课表立即刷新。
- [ ] 课程块与表格线之间空白很小，名称和地点优先换行展示，不应过早出现省略号。
- [ ] 截图添加课程页可以进入；选择截图后点击确定时，提示真实识别服务未接入，且不会直接写入课表。

## 待办核心

- [ ] 首页点击“下一件事”或底部待办入口进入待办列表页。
- [ ] 没有待办时，列表白色卡片中展示空态，不展示伪造待办。
- [ ] 点击待办页底部输入栏后弹出创建待办浮层；点击“手动创建待办”进入空白新建详情页。
- [ ] 新建普通待办：填写标题、内容、地点、重要程度和 tag 后保存，返回列表后可看到该待办。
- [ ] 新建 DDL 待办：切换到 DDL，选择截止日期和时间，保存后列表行显示完成按钮和 `DDL: M.DD HH:mm`。
- [ ] 新建持续时间待办：切换到持续，选择开始和结束时间，保存后列表行显示时间范围，不显示手动完成按钮。
- [ ] 标题为空、DDL 未设置、持续时间起止不合法时，保存失败并保留已输入内容。
- [ ] 点击待办行进入详情页，修改标题、内容、地点、类型、时间、重要程度、tag、重复设置后保存，列表刷新。
- [ ] 在详情页切换为普通待办时，起止时间和 DDL 被清空；切换为 DDL 时只保留 DDL；切换为持续时只保留起止时间。
- [ ] tag 选择页展示考试、作业、讲座、会议、生活、学习；可多选并返回详情页。
- [ ] tag 新增弹窗输入为空时“确定”不可点击；输入 tag 名后可保存，新增 tag 出现在 tag 列表中。
- [ ] 详情页点击删除图标或底部删除按钮会二次确认；确认后返回列表且该待办消失。
- [ ] 普通/DDL 待办点击完成按钮后变为已完成，标题划线弱化，并排在列表底部。
- [ ] 未结束的持续时间待办不能手动完成；结束时间已过的持续时间待办在进入列表或查询时自动变为已完成。
- [ ] 待办列表右上角筛选按钮打开右侧筛选边栏；日期全部/具体日期互斥，种类、完成情况、tag 可多选。
- [ ] 初始进入待办页时，种类筛选默认三项全选；取消三项后应用筛选展示无结果空态。
- [ ] 点击筛选侧栏外空白区域可关闭侧栏并返回待办页。
- [ ] 从首页 `DDL 提醒` 卡片进入待办页时展示默认待办列表，不自动套用 DDL 筛选。
- [ ] 选择筛选条件后点击“应用筛选”刷新列表；没有匹配结果时展示空态。
- [ ] 待办列表右上角批量按钮进入批量模式；左上角返回退出批量模式。
- [ ] 待办页右上角从左到右为批量编辑、筛选、添加待办 3 个按钮；添加待办为加号，点击后进入手动新建待办详情页。
- [ ] 待办页智能排序入口显示在列表白色大卡片左上区域，样式为图标加蓝色“智能排序”文字。
- [ ] 待办页智能排序左侧圆形勾选默认未选中；点击后先弹出确认排序弹窗，确认后变为选中；再次点击关闭智能排序并取消选中。
- [ ] 批量模式下左侧序号变为拖拽图标，并显示“长按左侧图标可拖拽调整顺序”；长按拖拽后退出批量模式，序号按新顺序恢复显示。
- [ ] 批量模式下可逐项勾选、全选、取消选中。
- [ ] 批量模式下手动选中一个待办后，右上角显示“取消选中”；点击后直接清空当前选择，不会先全选所有待办。
- [ ] 批量删除会二次确认；确认后所选待办消失。
- [ ] 批量完成会二次确认，并跳过持续时间待办；确认后普通/DDL 待办完成，持续时间待办保持原状态。
- [ ] 点击智能排序按钮会先弹窗提示覆盖手动排序；确认后按重要程度和紧急程度重新排序。
- [ ] 智能排序后若再手动拖拽，智能排序状态自动关闭，退出批量模式后按新的手动顺序显示。
- [ ] 待办列表页下拉刷新后会重新读取 repository，并保留当前筛选和排序状态。
- [ ] 有 DDL 的待办超过截止时间后仍保持未完成，列表日期/DDL 行以红色提示；持续时间待办到期仍自动完成。
- [ ] 普通/DDL/duration 时间展示为类似 `6.13 周六 15:30-16:30`；跨天 duration 展示起止两端日期和周几。
- [ ] 待办详情页先展示“重复设置”，再展示待办种类；重复可选择“仅一次 / 每天 / 每周 / 每两周”。
- [ ] 重复为“仅一次”时，DDL 和持续时间待办仍选择具体日期与时间。
- [ ] 重复为“每天”时，DDL 只选择几点，持续时间只选择起止时间，不出现日期选择。
- [ ] 重复为“每周/每两周”时，DDL 选择周几 + 几点，持续时间选择周几 + 起止时间，不出现具体日期选择。
- [ ] 重复 DDL 完成后，只完成当前周期；切到下一个周期后同一重复规则继续显示为未完成。
- [ ] 重复 DDL 当前周期未完成且超时后，下一个周期仍继续显示，不会因为上周期超时而整条消失。
- [ ] 删除重复待办后，整组重复规则消失，不再显示后续周期。
- [ ] 已完成重复周期记录超过 7 天后会被清理，但重复规则本身仍保留。
- [ ] 列表小字符合格式：`重复 DDL：每周 周三 18:30`、`重复 DDL：每两周 周三 18:30`、`重复 DDL：每天 18:30`、`重复 每周五 15:30 - 16:30`、`重复 每两周 周五 15:30 - 16:30`、`重复 每天 15:30 - 16:30`、`重复 普通待办`。
- [ ] 连续点击同一失败按钮时，只显示一个最新错误提示，不连续排队弹出。

## 创建、搜索、推荐与大目标拆分

- [ ] 首页或待办页点击底部输入栏后弹出创建待办浮层。
- [ ] 创建浮层未输入时展示“一句话”提示，右下角上箭头不可点击。
- [ ] 输入内容后上箭头可点击；点击后会把整句话作为普通待办标题创建，并进入待办页看到新增待办。
- [ ] 创建浮层点击“手动创建待办”进入空白新建详情页。
- [ ] 创建浮层点击右上角大目标拆分入口进入大目标拆分步骤 1；若已有输入，带入大目标名称。
- [ ] 从创建浮层或待办详情新建待办后，返回待办列表应立即刷新；若当前筛选条件不匹配，新待办可被筛选隐藏但不应丢失。
- [ ] 搜索页进入后搜索框自动聚焦。
- [ ] 输入关键词后点击搜索，能匹配 title/content/location/tags，且大小写不敏感。
- [ ] 搜索结果点击后进入对应待办详情页。
- [ ] 搜索历史 tag 可点击回填并执行搜索；清空历史会二次确认。
- [ ] 没有搜索结果时展示空态。
- [ ] 下一件事页可调节心情、启动意愿、焦虑三个 1-100 滑杆。
- [ ] 点击“推荐待办”进入推荐结果页；有待办时展示“不得不做/适合当前状态”候选并可点进详情。
- [ ] 没有用户待办时，推荐结果不伪造用户待办，只展示可添加的本地建议。
- [ ] “其他可以做的事”右侧 `添加到待办` 可添加为普通待办，添加后提示“已添加到待办”、按钮变为 `取消添加`，待办列表立即刷新可见；点击取消后提示“已取消添加”且语义清楚。
- [ ] 点击换一批按钮会重新获取推荐结果。
- [ ] 大目标拆分步骤 1 可填写大目标名称、最终 DDL、备注；未填名称或 DDL、DDL 早于今天时下一步不可用。
- [ ] 步骤 2 可添加小目标、选择计划完成日期、删除小目标；小目标日期不能早于今天或晚于最终 DDL。
- [ ] 至少 1 条小目标后才能进入预览。
- [ ] 步骤 3 按日期展示小目标时间线；点击确认生成会二次确认。
- [ ] 确认生成后，每条小目标生成一个 deadline 待办，DDL 为当天 23:59，优先级 4，tag 只包含由大目标名称生成的大目标 tag；不再默认添加 `学习`。

## 当前已知限制

- [ ] 当前不要求登录、云同步、后端调用或真实 AI 能力。
- [ ] 当前一句话创建、下一件事推荐和大目标拆分均为前端本地临时策略，不接真实 AI。
- [ ] duration 自动完成当前在进入列表/查询待办时触发；是否需要 App 启动即触发仍待产品确认。

## 本地持久化
