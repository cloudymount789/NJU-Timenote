# 手动测试清单

任务 1 构建完成后，用这份清单验证 Flutter 外壳、首页导航和基础空态，再进入后续更深的业务流程。

## 启动

- [ ] App 可以安装并在 Android 模拟器或真机启动。
- [ ] 首屏进入首页。
- [ ] 看不到 Flutter 默认计数器或 demo 内容。
- [ ] 手机竖屏下没有明显溢出、遮挡或文字重叠。

## 首页

- [ ] 顶部背景只有屏幕上方约四分之一是柔和蓝紫粉渐变。
- [ ] 页面下方约四分之三保持纯白或接近纯白。
- [ ] Header、三张白色卡片、卡片阴影、圆角和底部输入栏整体接近 Pencil 首页原型。
- [ ] 没有课程、待办或 DDL 时展示空态，不展示伪造业务数据。
- [ ] 点击右上角设置图标进入设置页，返回后回到首页。
- [ ] 点击“下一节课”卡片进入课表占位页，返回后回到首页。
- [ ] 点击“下一件事”卡片进入待办占位页，返回后回到首页。
- [ ] 点击左下角快速挑选图标进入下一件事占位页，返回后回到首页。
- [ ] 点击“DDL 提醒”卡片进入待办占位页，并显示已携带 `onlyDeadline=true` 语义。
- [ ] 点击右下角搜索图标进入待办搜索占位页，返回后回到首页。
- [ ] 点击底部输入栏文字后弹出创建待办底部浮层。
- [ ] 创建待办浮层在未输入时展示一句话提示、手动创建入口、大目标拆分入口，发送按钮为禁用态。
- [ ] 在创建待办浮层输入文字后，发送按钮变为可点击状态。

## 设置页

- [ ] 设置页可从首页进入。
- [ ] 页面展示“课表与作息”和“数据与分享”两个分区。
- [ ] 尚未实现的设置项清楚显示为待后续实现或禁用状态，不伪装成已完成能力。

## 路由壳

- [ ] 课表占位页可以进入添加课表占位页。
- [ ] 待办占位页可以打开创建待办浮层。
- [ ] 所有占位页面都可以返回上一页。

## 课表

- [ ] 首页点击“下一节课”进入课表页。
- [ ] 无课程时，课表页展示空态，不展示伪造课程。
- [ ] 点击课表右上角加号进入添加课表页。
- [ ] 添加课表页包含“手动添加课程”和“截图添加课程”两个入口。
- [ ] 手动添加课程页可以填写课程名称、任课教师、地点和备注。
- [ ] 未填写课程名称或地点时，点击“添加课程”会提示错误并保留表单内容。
- [ ] 点击“持续周次”可选择全部/单周/双周、起始周和结束周。
- [ ] 点击“上课时间”可选择周几、起始节和结束节。
- [ ] 结束周早于起始周、结束节早于起始节时会提示错误，不会保存。
- [ ] 添加成功后返回课表页，并立即看到新课程。
- [ ] 添加单节、跨多节、跨上午/下午的课程后，课表中能正确显示；跨上午/下午课程应被切成两个连续块。
- [ ] 在同一天同一节添加两门冲突课程后，课程块在同一格内左右排列。
- [ ] 长按课程块弹出删除确认；取消后课程仍在，确认后课程从课表消失。
- [ ] 截图添加课程页可以进入；选择截图后点击确定时，提示真实识别服务未接入，且不会直接写入课表。

## 待办核心

- [ ] 首页点击“下一件事”或底部待办入口进入待办列表页。
- [ ] 没有待办时，列表白色卡片中展示空态，不展示伪造待办。
- [ ] 点击待办页底部输入栏后弹出创建待办浮层；点击“手动创建待办”进入空白新建详情页。
- [ ] 新建普通待办：填写标题、内容、地点、重要程度和 tag 后保存，返回列表后可看到该待办。
- [ ] 新建 DDL 待办：切换到 DDL，选择截止日期和时间，保存后列表行显示完成按钮和 `DDL: M.DD HH:mm`。
- [ ] 新建持续时间待办：切换到持续，选择开始和结束时间，保存后列表行显示时间范围，不显示手动完成按钮。
- [ ] 标题为空、DDL 未设置、持续时间起止不合法时，保存失败并保留已输入内容。
- [ ] 点击待办行进入详情页，修改标题、内容、地点、类型、时间、重要程度、tag、重复设置后保存，列表刷新。
- [ ] 在详情页切换为普通待办时，起止时间和 DDL 被清空；切换为 DDL 时只保留 DDL；切换为持续时只保留起止时间。
- [ ] tag 选择页展示考试、作业、讲座、会议、生活、学习；可多选并返回详情页。
- [ ] tag 新增弹窗输入为空时“确定”不可点击；输入 tag 名后可保存，新增 tag 出现在 tag 列表中。
- [ ] 详情页点击删除图标或底部删除按钮会二次确认；确认后返回列表且该待办消失。
- [ ] 普通/DDL 待办点击完成按钮后变为已完成，标题划线弱化，并排在列表底部。
- [ ] 未结束的持续时间待办不能手动完成；结束时间已过的持续时间待办在进入列表或查询时自动变为已完成。
- [ ] 待办列表右上角筛选按钮打开右侧筛选边栏；日期全部/具体日期互斥，种类、完成情况、tag 可多选。
- [ ] 选择筛选条件后点击“应用筛选”刷新列表；没有匹配结果时展示空态。
- [ ] 待办列表右上角批量按钮进入批量模式；左上角返回退出批量模式。
- [ ] 批量模式下可逐项勾选、全选、取消全选。
- [ ] 批量删除会二次确认；确认后所选待办消失。
- [ ] 批量完成会二次确认，并跳过持续时间待办；确认后普通/DDL 待办完成，持续时间待办保持原状态。

## 创建、搜索、推荐与大目标拆分

- [ ] 首页或待办页点击底部输入栏后弹出创建待办浮层。
- [ ] 创建浮层未输入时展示“一句话”提示，右下角上箭头不可点击。
- [ ] 输入内容后上箭头可点击；点击后会把整句话作为普通待办标题创建，并进入待办页看到新增待办。
- [ ] 创建浮层点击“手动创建待办”进入空白新建详情页。
- [ ] 创建浮层点击右上角大目标拆分入口进入大目标拆分步骤 1；若已有输入，带入大目标名称。
- [ ] 搜索页进入后搜索框自动聚焦。
- [ ] 输入关键词后点击搜索，能匹配 title/content/location/tags，且大小写不敏感。
- [ ] 搜索结果点击后进入对应待办详情页。
- [ ] 搜索历史 tag 可点击回填并执行搜索；清空历史会二次确认。
- [ ] 没有搜索结果时展示空态。
- [ ] 下一件事页可调节心情、启动意愿、焦虑三个 1-100 滑杆。
- [ ] 点击“推荐待办”进入推荐结果页；有待办时展示“不得不做/适合当前状态”候选并可点进详情。
- [ ] 没有用户待办时，推荐结果不伪造用户待办，只展示可添加的本地建议。
- [ ] “其他可以做的事”右侧加号可添加为普通待办，添加后可取消添加。
- [ ] 点击换一批按钮会重新获取推荐结果。
- [ ] 大目标拆分步骤 1 可填写大目标名称、最终 DDL、备注；未填名称或 DDL、DDL 早于今天时下一步不可用。
- [ ] 步骤 2 可添加小目标、选择计划完成日期、删除小目标；小目标日期不能早于今天或晚于最终 DDL。
- [ ] 至少 1 条小目标后才能进入预览。
- [ ] 步骤 3 按日期展示小目标时间线；点击确认生成会二次确认。
- [ ] 确认生成后，每条小目标生成一个 deadline 待办，DDL 为当天 23:59，优先级 4，tag 为学习。

## 任务 1 已知限制

- [ ] 当前不要求真实本地持久化。
- [ ] 当前不要求登录、云同步、后端调用或真实 AI 能力。
- [ ] 当前一句话创建、下一件事推荐和大目标拆分均为前端本地临时策略，不接真实 AI。
- [ ] duration 自动完成当前在进入列表/查询待办时触发；是否需要 App 启动即触发仍待产品确认。
