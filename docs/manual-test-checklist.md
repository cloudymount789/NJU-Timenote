# 手测清单

## 待办 Tag 管理

- 在待办详情进入 tag 选择页，点击右上角加号新增 tag，确认后留在 tag 选择页且新 tag 自动选中，不出现崩溃或断言报错。
- 在 tag 选择页长按任意 tag，出现二次确认弹窗；点取消时 tag 保留。
- 在 tag 删除确认弹窗点删除后，该 tag 从 tag 列表和当前选择中消失。
- 删除 tag 后，已存在待办中的同名 tag 引用会被移除，待办本身不会被删除；重新进入待办详情和筛选侧栏不应崩溃。

## 待办智能排序

- 在待办列表启用智能排序后，入口文案显示“智能排序已开启”；退出并重新进入待办页，状态仍应保持开启。
- 智能排序开启时新增、编辑、删除、完成或取消完成待办，列表应自动按智能排序刷新，不需要再次点击智能排序。
- 智能排序开启后再次点击“智能排序已开启”，应关闭智能排序并显示“开启智能排序”。
- 智能排序开启时进入批量模式，长按左侧图标拖拽手动调整顺序；退出后智能排序状态关闭，列表按手动顺序显示。
- 准备两个待办：一个截止时间更近但重要程度低，另一个截止时间更晚但重要程度高；启用智能排序后，更紧急的待办应排在前面。
- 重启 App 后进入待办页，若重启前智能排序处于开启状态，应恢复为开启并继续自动排序。

## 持续时间待办时间填写

- 新建或编辑待办，切换为“持续”，点击“开始时间”，选择日期和时间后，结束时间应自动显示为开始时间后 1 小时。
- 选择开始时间完成后，应自动弹出“选择结束时间”的时间选择器，不需要再次从日期开始选择。
- 开始时间设置为深夜，例如 23:30 时，默认结束时间应落到次日 00:30；若结束时间选择为早于开始时间的时刻，应按次日结束处理。

## 待办列表序号

- 准备较多未完成待办，上下滚动列表多次；左侧序号应保持从 1 开始按当前列表顺序递增，不应随着滚动继续变大。
- 切换筛选或智能/手动排序后，序号应基于当前显示顺序重新稳定计算。
- 将某个普通/DDL 待办标记完成后，它应移动到底部且不显示序号；标题仍与未完成待办标题左侧对齐。
