# 手测清单

## 待办 Tag 管理

- 在待办详情进入 tag 选择页，点击右上角加号新增 tag，确认后留在 tag 选择页且新 tag 自动选中，不出现崩溃或断言报错。
- 在 tag 选择页长按任意 tag，出现二次确认弹窗；点取消时 tag 保留。
- 在 tag 删除确认弹窗点删除后，该 tag 从 tag 列表和当前选择中消失。
- 删除 tag 后，已存在待办中的同名 tag 引用会被移除，待办本身不会被删除；重新进入待办详情和筛选侧栏不应崩溃。

## 待办智能排序

- 在待办列表启用智能排序后，智能排序图标保持启用状态；再次点击只重新执行智能排序，不应关闭。
- 智能排序开启时新增一个更紧急的 DDL/持续时间待办，返回列表后该待办自动按智能排序进入正确位置。
- 智能排序开启时进入批量模式，长按左侧拖拽图标手动调整顺序；退出后智能排序状态关闭，列表按手动顺序显示。
- 准备两个待办：一个截止时间更近但重要程度低，另一个截止时间更晚但重要程度高；启用智能排序后，更紧急的待办应排在前面。
