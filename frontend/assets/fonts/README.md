# 字体资源

思源宋体（Source Han Serif SC）字体文件放在这里。

当前已放入 Adobe 官方 Source Han Serif 2.003R 的简体中文 OTF 常用字重：

- `SourceHanSerifSC-Regular.otf`，weight 400
- `SourceHanSerifSC-SemiBold.otf`，weight 600
- `SourceHanSerifSC-Bold.otf`，weight 700

`LICENSE.txt` 为随字体一起保留的 SIL Open Font License 1.1 文本。字体已在 `frontend/pubspec.yaml` 的 `flutter.fonts` 中注册。
