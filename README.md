# NJU TimeNote / 南雍时序

> 面向大学生的本地优先时间管理 App，预留 AI / 智能体扩展  
> 参赛方向：EL 程序设计大赛 交互组 + AI 智能体创新专项  
> 仓库地址：https://github.com/cloudymount789/NJU-Timenote.git

## 项目简介

**NJU TimeNote / 南雍时序** 是一款围绕大学生日常学习生活设计的本地优先时间管理 App。它把课表、待办、DDL、讲座会议、学习目标和个人状态收拢到同一个入口中，帮助学生把散落在课程表、群通知、备忘录、聊天记录和脑子里的事情，转化为今天看得见、找得到、知道先做哪件的行动提示。

大学生并不缺“可以记东西”的工具，真正缺的是一个懂学生时间结构的工具：它知道一节课会占掉固定时间，知道实验报告有 DDL，知道讲座不是待办而是一段日程，知道“今天很累”时不该再把任务压力继续加满。NJU TimeNote 关注的是让用户在打开 App 的第一眼，就能知道自己今天有什么、现在最适合先做什么。


## 作品目标

NJU TimeNote 的目标不是做一个“功能很多”的效率工具，而是做一个真正能被大学生每天打开、打开以后立刻有用的轻量学习生活助手：

1. **让信息不再散落**：把课程、作业 DDL、考试、讲座、会议、社团任务和临时想法收进同一个系统，减少从群聊、备忘录、课表和日历之间来回翻找的混乱。
2. **让记录像说一句话一样简单**：用户想到一件事时，不需要先思考它属于哪种表单，只要快速输入，就能把事情稳稳落地。
3. **在不知道做什么时给出下一步**：当用户面对一堆课程、DDL 和待办发呆时，系统可以结合事项类型、紧急程度和用户当前心理状态，推荐几个更适合现在开始的“下一件事”。
4. **把细碎功能做到贴心**：三类待办、智能排序、手动排序、批量操作、待办重复规则、tag、搜索、筛选、首页速览、多份课表与周数切换，都是围绕大学生每天真的会遇到的小麻烦设计的。
5. **让目标从焦虑变成行动**：面对“复习高数”“准备程序设计期末”这类大目标，系统帮助用户拆成每天可以完成的小任务，降低开始行动的心理门槛。
6. **免费、轻量**：核心数据本地优先，基础能力离线可用，时间管理不应成为新的消费压力或配置负担。
7. **让智能体升级有真实土壤**：课表、待办、目标和状态等，都是未来 Agent 能够读取、理解，从而给出更个性化推荐的“自动上下文”。

## 核心亮点

### 统一入口：把散落的信息收回来

你是否曾经临近讲座开始才想起地点没有记，只能回到刷屏的群聊里翻通知；或者晚上坐到桌前，才发现作业、会议、考试复习、社团任务全都挤在脑子里，却不知道先看哪一个？

**NJU TimeNote 把课表、待办、DDL、讲座会议和临时想法放进同一个入口。** 首页直接提供下一节课、下一件事、DDL 提醒和一句话创建入口，让用户打开 App 的第一眼就能完成速览：接下来去哪、最近要交什么、现在可以先做什么。它不是把功能堆起来，而是把学生一天里最容易打断注意力的信息收回来。

### 细致建模：不是所有待办都应该长得一样

你是否曾经把“整理桌面”“周日晚前提交实验报告”“周三 19:00-21:00 参加讲座”都放进同一个清单，结果列表看起来整齐，真正安排时却很难判断哪个会占用时间、哪个已经快截止、哪个只是有空再做？

**NJU TimeNote 把待办细分为普通待办、有 DDL 待办和有持续时间待办。** 普通待办适合随手记录，DDL 待办适合作业提交、报名截止、小组任务等必须在某个时间前完成的事项，持续时间待办则适合讲座、会议、考试、活动等会占据具体时间段的安排。持续时间待办结束前不能被随手完成，结束后可以自动完成；DDL 超时后仍保留未完成状态并突出提醒。每一种事件都有自己的语义，列表才真正贴近生活。

未来，我们还会把这一套三类待办模型接入 AI 识别：用户粘贴一句群通知或老师要求时，系统不仅能提取标题和时间，还能判断它更像普通任务、DDL，还是会占用一段时间的活动。

### 排序自由：智能建议和手动掌控都要有

你是否曾经面对一长串待办，只能凭感觉决定先做哪个；或者用了自动排序以后，又觉得系统不懂你真正想先完成什么？

**NJU TimeNote 同时支持智能排序和手动排序。** 智能排序参考四象限任务法，把紧急程度、重要程度、DDL 和完成状态纳入考虑，帮助用户从一堆事情里找到更值得先看的事项；手动排序则保留给那些想自己制定执行顺序的人。你可以让系统先帮你理一遍，也可以亲手把今天的节奏排成自己舒服的样子。

### 待办管理：把烦人的重复操作降下来

你是否曾经想删掉一批过期任务，却只能一条条点；想把几个小任务标记完成，却被重复确认折磨；想找一条很久以前的待办，却只记得 tag 或模糊关键词？

**NJU TimeNote 在待办管理里做了很多小而实的细节。** 它支持批量完成和批量删除，减少重复操作；支持重复待办逻辑，让每天、每周、每两周的事项不必反复新建；支持待办重要性评分，支持 tag 归档，把作业、考试、讲座、会议、生活、学习等事项分类保存；支持待办搜索，名称、内容、地点和 tag 都可以被检索；支持筛选侧栏，可以按日期、三种待办种类、完成状态和 tag 组合筛选。它关心的不是“能不能做”，而是“做起来烦不烦”。

### 课表系统：让课程真正成为时间管理的底座

你是否曾经遇到换学期、重修、辅修、双学位、交换课程，或者只是想看朋友的课表，却发现课表工具默认你永远只有一份课表？

**NJU TimeNote 支持多份学期课表和更细致的课表归属。** 用户可以管理不同学期课表，设置课表归属（人）、学年范围、春/秋学期、开学日期和持续周数；课表页支持学期切换、周数切换，并按所选学期显示对应课程。课程可以手动添加、编辑和删除，支持持续周次、单双周、上课节次、跨上午/下午/晚间显示、冲突课程并排展示，也支持“仅删除这一次课”和“删除所有课程”两种删除范围。课表不只是一个表格，而是大学生日程结构的底座。

未来，我们还会继续增强课表导入和识别能力，增加教务系统导入和OCR截图识别导入课表功能，大大减少录入课表的成本。

### 下一件事推荐：不知道做什么时，先给一个能开始的

你是否曾经打开待办列表，看见很多事，但自己此时却心情烦躁，一件都不想开始？这时用户需要的往往不是一份完整计划，而是一个“现在就做这个”的轻推。

**NJU TimeNote 做的是下一件事推荐，而不是空泛的自动计划。** 用户可以输入当前心情、启动意愿和焦虑程度，系统再结合本地待办给出推荐结果。状态好时，可以优先处理更重要、更紧急的任务；状态差时，也可以先从低压力的小事启动。它能在用户卡住的时候，给出一个更容易开始的下一步。

未来，我们还会把下一件事推荐升级为 AI 智能推荐：让 AI 结合课表、DDL、待办类型、tag、历史完成情况和当前状态，给出更个性化的推荐理由。

### 大目标拆分：把“我要复习”拆成今天能做的一步

你是否曾经写下“准备期末考试”“复习高数”“完成课程项目”，然后因为目标太大而迟迟没有开始？

**NJU TimeNote 提供大目标拆分流程。** 用户可以填写目标名称、最终 DDL 和备注，再手动添加多个小目标，系统会把这些小目标批量生成 DDL 待办。它不是替用户编一份空洞计划，而是帮助用户把“我要复习”变成“今天整理第一章笔记”“明天完成一组习题”这样可执行、可检查的小步骤。

未来，我们还会接入 AI 辅助拆分：用户输入一个大目标后，AI 可以先给出阶段任务和小目标草稿，用户确认、修改后再加入待办。AI 负责降低启动门槛，最终安排仍交给用户掌控。

### 本地优先：先成为可靠工具，再谈更多能力

你是否曾经只是想记一件小事，却被登录、同步、会员、网络状态挡在门外？

**NJU TimeNote 当前坚持本地优先。** 课程、待办、标签、设置、课程颜色映射、排序状态和重复完成记录都通过本地 JSON 快照保存；即使没有后端、没有登录、没有真实 AI 服务，核心查看、编辑、筛选、排序和推荐演示流程仍然可以运行。对学生来说，时间管理工具首先应该可靠、轻量、随手可用。

## 竞品分析与差异化优势

时间管理领域已经有很多成熟产品。Todoist 和 TickTick 擅长通用任务管理，WakeUp 课程表擅长高校课表展示，Google Calendar 是成熟日历工具，MyStudyLife 面向学生规划，通用大模型也可以临时给出建议。NJU TimeNote 并不试图在每个单点能力上重新发明一遍成熟工具，而是把这些能力放回大学生的真实一天里重新组织。

我们的优势不是“也有课表、也有待办、也有推荐”，而是把 **课表底座、三类待办、首页速览、细致管理、下一件事推荐、大目标拆分和本地优先体验** 串成一个学生场景闭环。用户不是为了管理工具而管理工具，而是打开 App 就能知道：我接下来去哪，最近要交什么，现在先做哪件事。

| 对比维度 | 常见竞品的强项 | NJU TimeNote 的差异化优势 |
| --- | --- | --- |
| 统一入口 | 单独的课表、待办、日历、聊天工具都能完成各自任务，但信息仍然分散。 | NJU TimeNote 把下一节课、下一件事、DDL 提醒和一句话创建入口放在首页，让学生第一眼就完成速览，不必为了找一条通知在多个 App 之间切换。 |
| 事项模型 | 通用待办 App 通常用同一套清单承载所有任务，灵活但需要用户自己解释语义。 | NJU TimeNote 直接区分普通待办、DDL 待办和持续时间待办，可添加重要程度，tag等，添加了许多适配学生真实需要的细节，让使用的体验感更贴近学生生活。 |
| 贴心细节 | 成熟效率工具功能强，但项目、过滤器、日历、标签体系容易变复杂。 | NJU TimeNote 只保留大学生高频需要的细节：智能排序、手动排序、批量完成/删除、重复规则、tag 归档、名称/tag 搜索和多条件筛选，够用、顺手、不喧宾夺主。 |
| 课表底座 | 课程表工具展示课程很强，但课程通常只是“可查看的信息”。 | NJU TimeNote 把课表作为时间结构底座：支持多份学期课表、课表归属、学年学期、周数切换、单双周、冲突课程和单次删除，也为下一件事推荐提供上下文。 |
| 下一件事 | 通用工具多展示任务列表，用户仍要自己判断现在先做什么；AI 聊天则需要反复补充上下文。 | NJU TimeNote 已完成基于本地待办和状态滑杆的推荐闭环。未来，我们还会升级为 AI 智能推荐，结合课表、DDL、待办类型、tag 和历史完成情况给出更个性化的推荐理由。 |
| 大目标 | 很多工具可以记录长期目标，但目标经常停留在一句“我要复习”。 | NJU TimeNote 已支持把大目标拆成多个 DDL 待办。未来，我们还会接入 AI 辅助拆分，让 AI 先给出小目标草稿，用户确认后再真正加入待办。 |
| 本地优先 | 很多产品依赖账号、云同步、会员能力或持续联网体验。 | NJU TimeNote 当前核心数据保存在本地，课程、待办、tag、设置、排序状态和重复完成记录都能持久化，先保证工具随手可用，再逐步加入 AI 和 OCR 增强。 |

因此，NJU TimeNote 真正想赢的地方，是 **学生事件理解 + 贴心细节落地**。它不追求成为最复杂的效率系统，而是专注把学生每天都会遇到的场景，转化为不同类型的事项、不同优先级的候选任务和更清楚的下一步行动。

如果说传统待办工具解决的是“我有哪些任务”，课程表工具解决的是“我什么时候上课”，通用 AI 解决的是“我临时问一次你临时答一次”，那么 NJU TimeNote 想解决的是：

> **我今天真正有多少时间？哪些事不能拖？我现在最适合先做哪一件？**

## 使用指南

### 环境要求

- Flutter SDK，当前 `frontend/pubspec.yaml` 使用 Dart SDK `^3.12.1`
- Android Studio / Android SDK
- 可连接的 Android 真机或模拟器
- Windows 桌面工程入口已生成，可用于本地预览，但项目首要目标是 Android

### 获取项目

```powershell
git clone https://github.com/cloudymount789/NJU-Timenote.git
cd NJU-Timenote
```

### 安装依赖

```powershell
cd frontend
flutter pub get
```

### 运行 App

```powershell
flutter run
```

如需指定设备，可先查看设备列表：

```powershell
flutter devices
```

### 常用检查命令

以下命令均在 `frontend/` 目录下执行：

```powershell
dart format lib test
flutter analyze
flutter test
flutter build apk --debug
```

如果本机 PowerShell 中 Gradle 找不到 Java，可以临时使用 Android Studio 自带 JDK：

```powershell
$env:JAVA_HOME='D:\Program Files\Android Studio\jbr'
$env:PATH="$env:JAVA_HOME\bin;$env:PATH"
```
